サイトを作らなくてもOK：独自ドメインで仕事用メールアドレスを持つ手順

最終更新日: 2026-09-08

こんな方向け: 自分のサイトを公開する目的ではなく、会社名・屋号入りの独自ドメインで仕事用のメールアドレスだけを持ちたい人が、ドメイン取得からメール利用開始までに必要な手順と注意点を知りたい

独自ドメインは、サイトを公開するためだけでなく、「会社名や屋号が入ったメールアドレスを持つ」ためだけに取得されることもあります。この場合も、独自ドメインをメールで使うにはレンタルサーバーとの契約とサーバー側でのドメイン追加が必要である点は、サイトを公開する場合と同じです。本記事はメール利用に的を絞った手順で、WordPressでのサイト構築は扱いません（サイト公開の手順は本サイトの「はじめてのサイト・ブログ開設」記事を参照してください）。操作画面の名称・手順はエックスサーバーを例にしており、他社のレンタルサーバーでは画面名や設定項目が異なる場合があります。料金の比較は本サイトの「独自ドメイン取得サービス比較」「レンタルサーバー比較」の記事をご覧ください。

手順

  1. 1. レンタルサーバーを契約する（メールだけが目的でもサーバー契約は必要）

    独自ドメインのメールアドレスは、ドメイン取得サービス単体では使えません。エックスサーバー公式マニュアル「メールアカウントの追加」によれば、メールアカウントの追加は契約中のレンタルサーバー側の操作で行い、無料お試し期間中はメールアカウントの追加ができないとされています（新旧サーバーパネル共通）。お試し期間中にメール機能まで動作確認したい場合はこの制約に注意してください。サーバー選びの料金比較は本サイトの「レンタルサーバー比較」記事を参照してください。

  2. 2. 独自ドメインを取得する（サイトを作らない場合も同じ）

    サイトを公開しない場合でも、メールに使う独自ドメイン自体は別途取得が必要です。ドメイン取得サービスの比較は本サイトの「独自ドメイン取得サービス比較」記事を参照してください。

  3. 3. サーバーの「ドメイン設定」でドメインを追加する（メールアカウント作成の前提条件）

    エックスサーバー公式マニュアル「メールアカウントの追加」には、事前に「ドメイン設定」でメールアカウントを作成したいドメインを追加しておく必要があると明記されています。この「ドメイン設定」はサイトを公開する場合と同じ操作です。エックスサーバー公式マニュアル「ドメイン設定」によれば、反映には数時間〜最大24時間程度かかる場合があり、ドメイン取得サービスとレンタルサーバーが別会社の場合は、追加でドメイン取得サービス側の管理画面でネームサーバーをレンタルサーバー側の値に変更する必要があります（この反映は他社ネームサーバー側の都合により最大72時間程度かかる場合があるとされます）。サイトを公開しない場合、無料独自SSLの設定は必須ではありません（SSLはhttps化、すなわちWeb表示のための設定のため）。

  4. 4. メールアカウントを追加する

    エックスサーバー公式マニュアル「メールアカウントの追加」の手順では、サーバーパネルにログインして「メールアカウント設定」を選び、「メールアカウントを追加」から登録方式で「個別」を選択し、アカウント名・パスワード・容量・メモを入力して追加します。追加時に「ドメイン認証」画面が表示される場合は、画面の案内に従って認証を完了させる必要があります。

  5. 5. メールを使い始める：Webメールかメールソフトかを選ぶ

    エックスサーバー公式サポートのFAQ「メールの設定方法」によれば、メールソフトを設定しなくてもブラウザだけでメールを送受信できる「Webメール」が用意されています。パソコンやスマートフォンにメールソフトを追加設定したい場合は、受信・送信サーバー情報を契約後にサーバーパネルの案内にもとづいて入力します。具体的な受信/送信サーバー名は契約したサーバー・ドメインの組み合わせで変わるため、本記事では個別の値は記載していません（未確認）。

判断に迷ったら

  • サイトを作る予定があるかないか → ある場合は「はじめてのサイト・ブログ開設」記事の手順とあわせて進める。無い場合もレンタルサーバー契約とドメイン設定までの手順は共通で、無料独自SSLの設定とWordPressインストールは不要
  • 無料お試し期間中にメール機能まで確認したいか → エックスサーバー公式マニュアルによれば、お試し期間中はメールアカウントを追加できないため、メール機能の動作を確認するには契約が必要になる
  • ドメイン取得サービスとレンタルサーバーが別会社か → 別会社の場合、ネームサーバーの変更が追加で必要になり、反映に時間がかかることがある
  • メールソフトをインストールしたくないか → Webメールを使えばブラウザだけで送受信できる
