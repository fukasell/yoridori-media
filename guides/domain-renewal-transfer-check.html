ドメインの更新前に立ち止まる：他社への移管を検討するときの確認ポイント

最終更新日: 2026-09-08

こんな方向け: すでに持っている独自ドメインの更新時期が近づいている人が、そのまま更新するか他社（別のドメイン管理業者）へ移管するかを、費用の数え方・申請条件・メールやサイトへの影響の観点から判断したい

独自ドメインは「更新料が高い会社から安い会社へ移管すればいい」と単純に語られがちですが、移管（トランスファー）には申請できる条件、費用の数え方、DNS設定への影響など、更新料金の比較だけでは分からない論点があります。本記事は、新規取得・更新の料金を横並びにした本サイトの「独自ドメイン取得サービス比較」記事とは異なり、すでにドメインを持っている人が更新の直前に立ち止まって、そのまま更新するか他社へ移管するかを判断するための確認ポイントを、各事業者の公式情報にもとづいて整理したものです。移管すれば必ず安くなる、移管してもメールが絶対に止まらない、といった断定はしていません。条件は事業者・対象ドメイン（TLD）によって異なるため、実際に移管する前に必ず各社公式サイトで最新情報をご確認ください。なお、本記事から遷移できる「独自ドメイン取得サービス比較」記事には、成果報酬型のアフィリエイト広告（提携リンク）を含みます。

手順

  1. 1. 「更新」と「移管」の違いを整理する

    更新は今契約している事業者とのまま契約期間を延ばす手続きで、移管（トランスファー）はドメインの管理を別の事業者（レジストラ）に変える手続きです。お名前.com公式note「ドメイン移管とは？」によれば、ドメイン自体はICANNの共通ルールのもとで運用されているため、どの事業者が管理してもドメイン名自体の機能や価値、SEO評価は変わらないとされています。まずこの2つが別の選択肢であることを前提に、費用と条件を個別に比較する必要があります。

  2. 2. 移管の費用を、更新料金と同じ土台で比較する

    お名前.com公式noteによれば、移管手数料（同note記載では目安として約1,000〜2,000円程度）は実質的に1年分の更新料金として扱われるとされています。つまり「移管手数料」単体の安さではなく、「移管先での移管費用＋その後毎年かかる更新料金」と「今の事業者で更新し続けた場合の更新料金」を、同じ対象TLD・同じ税込区分で並べて比較する必要があります。例としてXServerドメインの公式価格表（2026-09-08確認）では、.comの移管料金は1,721円（税込）で更新料金と同額、.jp（ローマ字）は3,102円（税込）で同じく更新料金と同額と明記されています。取得時に表示される0円等のキャンペーン価格（同ページでは2026/9/1 12:00〜2026/10/30 17:00の期間限定と注記）は移管には適用されない点に注意してください。お名前.comの移管料金は対象TLDごとの公式ページで個別に確認する必要があり、本記事では具体的な金額を確認できていません（2026-09-08時点で未確認）。

  3. 3. 移管を申請できる条件（有効期限・認証コード・ロック解除）を確認する

    お名前.com公式ヘルプ「移管申請までの手順をチェックしよう」によれば、JPドメイン（汎用・都道府県型・属性型）は有効期限が31日以上、gTLD（.com/.net/.orgなど）は15日以上残っていないと移管を申請できず、不足している場合は移管元の事業者で先に更新したうえで申請するよう案内されています。移管には移管元の事業者から取得するAuthCode（認証コード）が必要で、gTLDドメインについては申請前にトランスファーロックを解除しておく必要があるとも明記されています（JPドメインについてのロック解除の要否はこのページに記載がありません）。これはお名前.comが移管を受け入れる側としての説明のため、移管先が別の事業者の場合は条件が異なる可能性があります（未確認）。移管先の公式ページも合わせて確認してください。

  4. 4. 移管が完了するまでの期間と、期限切れのリスクを考える

    エックスサーバー公式FAQ「ドメイン移管の手続きにかかる日数を教えてください。」によれば、移管はお申し込み後1週間〜10日程度で完了するとされ、上位機関を介した手続きのため事業者側で完了のタイミングを早めることはできないと説明されています。お名前.com公式noteでも、申請から数日〜10日前後で完了し、移管の承認には5〜14日程度の期限があるとされています。3.の条件（残り有効期限）ぎりぎりで移管に着手すると、承認や手続きが間に合わず有効期限切れのリスクが生じ得るため、更新期限の直前ではなく余裕を持って判断・着手することが重要です。

  5. 5. DNS設定・メールへの影響を確認する

    エックスサーバー公式FAQによれば、ドメイン移管はドメインの管理会社を変更する手続きであり、ネームサーバーなどのDNS設定は変更されず移管元の設定がそのまま引き継がれるため、運用中のWebサイトやメールへの影響はないとされています（「ドメイン移管の際に、ネームサーバーなどDNSは変更されますか？」「ドメインを移管したいのですが、運用しているWebサイトやメールに影響はありますか？」の各FAQ）。一方でお名前.com公式noteは、ネームサーバー自体の変更を伴う場合は24〜72時間程度Webサイトやメールの表示が不安定になることがあり、DNS設定（メールサーバーの情報であるMXレコードなど）が引き継がれない場合は一時的にメールが使えなくなることがあるとして、移管前に現在のDNS設定を控えておき、移管完了後に正しく維持されているか確認するよう案内しています。つまり「登録事業者だけを変える」場合と「あわせてネームサーバー（DNSホスティング先）も変える」場合とで話が変わるため、自分がどちらを行うのかをまず確認してください。移管元の事業者がドメインと合わせて無料のDNS設定サービスも提供している場合、移管完了時点でそのサービス自体が使えなくなることがあるため、DNSホスティング先を変える予定があるなら移管前に移行先を用意しておく必要があります。

  6. 6. 移管先の候補を比較記事で確認する

    本サイトが保存しているA8.netの提携プログラムページ（2026年9月7日時点、A8メディア会員向け管理画面の成果報酬欄）を確認したところ、お名前.com（プログラムID s00000000018015）は「お名前.comへのドメイン移管：1100円」という移管専用の成果報酬が明記されており、XServerドメイン（プログラムID s00000001642007）も「ドメイン取得・移管1000円」のように取得と移管が同じ成果報酬区分にまとめて明記されていました。このため、この2社については移管の申込みが成果報酬の対象になり得ることを確認しています。ただし、これは成果報酬の一覧表示にもとづく確認であり、対象外ドメインの条件などプログラム詳細規約の全文までは確認できていません（未確認）。実際に成果報酬の対象になるかどうか、除外条件の詳細は、申込み前に各社公式サイトでご確認ください。ムームードメインは、本記事の確認時点で提携（アフィリエイト提携）が成立していないため、この2社と同列の成果報酬の案内はできません。費用・条件の詳細な比較は、本サイトの「独自ドメイン取得サービス比較」記事をご覧ください。

判断に迷ったら

  • 更新期限まで残り15日（gTLD）／31日（JPドメイン）を切っている場合 → お名前.com公式ヘルプによれば移管を申請できないため、まず今の事業者で更新してから移管を検討する
  • 移管と合わせてネームサーバー（DNSホスティング先）も変える予定がある場合 → お名前.com公式noteによれば表示やメールが一時的に不安定になることがあるため、移管前に現在のDNS設定（特にメールのMXレコード）を控えておく
  • 登録事業者だけを変え、ネームサーバーは変えない場合 → エックスサーバー公式FAQによれば、この場合はDNS設定がそのまま引き継がれ、運用中のWebサイト・メールへの影響はないとされている
  • 費用面のメリットを確認したい場合 → 「移管費用」単体ではなく「移管費用＋移管後に毎年かかる更新料金」と「今のまま更新し続けた場合の更新料金」を、同じ対象TLD・同じ税込区分で比較する。対象TLDごとの移管料金は各社公式ページでの確認が必要（本記事で確認できたのはXServerドメインの一部TLDのみ）
