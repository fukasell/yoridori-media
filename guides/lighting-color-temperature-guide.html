照明の色温度と明るさの選び方：K と lm の読み方

最終更新日: 2026-09-08

こんな方向け: 部屋の雰囲気を変えたいが、照明のスペックの見方が分からない人

家具を買い替えるより、照明を1つ変えるほうが部屋の印象は変わります。ただし商品ページの「2700K」「810lm」といった数値の意味が分からないと選びようがありません。この2つはどちらも規格化された数値で、商品ページに必ず書かれています。ここではその読み方だけを整理します。実際の見え方は部屋の広さ・壁の色・照明の数で変わるため、数値は目安として使ってください。

手順

  1. 1. 色温度（K＝ケルビン）で雰囲気が決まる

    数値が低いほどオレンジ寄り、高いほど青白くなります。一般に2700K前後が「電球色」、3500K前後が「温白色」、5000K前後が「昼白色」と表記されます。同じ部屋でも色温度を変えるだけで印象が変わるため、まずここを決めます。

  2. 2. 明るさ（lm＝ルーメン）は光の量

    ワット（W）は消費電力であって明るさではありません。LEDでは同じ明るさでもWが小さいため、比較にはlmを使います。商品ページにlmの記載がない照明は、明るさを比べようがありません。

  3. 3. 用途ごとに必要な明るさの目安を知る

    部屋全体を照らすシーリングライトと、手元を照らすスタンドでは必要なlmが違います。メーカーは適用畳数を併記していることが多いので、まずはその表記に合わせるのが確実です。畳数表記は日本工業規格に基づく目安です。

  4. 4. 調光・調色に対応しているか確認する

    調色対応なら1台で色温度を変えられます。夜は電球色、作業時は昼白色といった使い分けができるため、1部屋で複数の用途がある場合は候補になります。対応していない場合は色温度を後から変えられません。

  5. 5. 口金と器具の対応を確認する

    電球を替えるだけの場合は口金サイズ（E26／E17など）を合わせます。器具ごと替える場合は取付方式（引掛シーリング等）を確認します。ここが合わないと物理的に付きません。

判断に迷ったら

  • 落ち着いた部屋にしたい → 2700K前後の電球色を軸にする。同じ器具でも色温度を下げるだけで印象が変わる
  • 作業もする部屋 → 調色対応を選ぶか、電球色の全体照明＋昼白色の手元照明に分ける
  • lmの記載がない → 明るさを比較できないため候補から外す。Wでは比較にならない
  • 賃貸で工事したくない → 引掛シーリング対応の器具か、コンセント式のスタンドを選ぶ
